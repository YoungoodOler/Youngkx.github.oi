## 一、什么是随机化（Randomization）？

随机化，就是在程序的执行过程中引入随机因素，使算法的某些行为不再完全由输入数据决定。

例如，给定数组：

```
int a[] = {1, 2, 3, 4, 5};
```

如果我们每次都选择第一个元素作为快速排序的基准，那么对于某些特定输入，快速排序可能退化到 \\(O(n^2)\\)。

但如果我们随机选择基准：

```
int p = rand() % n;
```

就可以降低特定输入反复触发最坏情况的风险。

这就是随机化算法的一种典型应用。

需要注意：

随机化不等于随机乱做，而是利用随机性改善算法的效率、稳定性或求解能力。

随机化算法可以分成两种典型类型：

| 类型             | 特点                    | 例子        |
| -------------- | --------------------- | --------- |
| Las Vegas 算法   | 结果正确性有保证，运行时间可能随机变化   | 随机快速排序    |
| Monte Carlo 算法 | 运行时间或试验次数可控，但结果可能存在误差 | 蒙特卡洛估计圆周率 |

当然，随机化也可以仅用于生成测试数据，不一定构成算法本身。

## 二、什么是伪随机数？

### 1. 计算机的随机数真的随机吗？

通常情况下，我们在 C++ 中使用的随机数生成器都是伪随机数生成器（Pseudorandom Number Generator，PRNG）。

它们不是凭空产生随机数，而是通过确定的数学算法生成一串数字。

假设某个生成器的状态变化规律为：

\\[ X\_{n+1}=(aX_n+c)\bmod m \\]

这是经典的线性同余生成器（LCG）形式。

其中：

- \\(X_n\\)：当前状态
- \\(X\_{n+1}\\)：下一个状态
- \\(a,c,m\\)：固定参数
- \\(X_0\\)：初始状态，通常由随机种子决定

举个简单例子，假设：

\\[ X\_{n+1}=(5X_n+3)\bmod 16 \\]

设置初始种子：

\\[ X_0=2 \\]

计算：

\\[ X_1=(5\times2+3)\bmod16=13 \\]

\\[ X_2=(5\times13+3)\bmod16=4 \\]

\\[ X_3=(5\times4+3)\bmod16=7 \\]

于是得到：

```
13 4 7 6 1 8 ...
```

如果再次使用种子 `2`，得到的序列仍然完全相同。

这就是伪随机数的本质：

看起来没有规律，但实际上由确定的算法生成，可以复现。

### 2. 为什么叫“伪”随机？

因为它满足两个重要特点：

1. 生成的数字在统计意义上可以表现得像随机数。
2. 如果知道生成算法和初始状态，就可以预测后续数字。



## 三、什么是随机种子（Random Seed）？

随机种子是用于初始化伪随机数生成器的一个值。

你可以把随机数生成器理解为一台机器：

```
随机种子
   ↓
初始化随机数生成器
   ↓
生成第一个随机数
   ↓
更新内部状态
   ↓
生成第二个随机数
   ↓
更新内部状态
   ↓
生成第三个随机数
   ↓
...
```

注意这里有一个关键概念：

种子不一定就是生成器的完整内部状态。

例如 `mt19937` 的内部状态很大，而我们可以只用一个 32 位整数作为种子初始化它。

### 相同种子意味着什么？

对于相同的随机数生成算法及其实现参数：

```
srand(42);
```

如果两次都从种子 `42` 开始，后续 `rand()` 产生的序列就会相同。

但不同平台的 `rand()` 算法可能不同，因此不能保证所有编译器、操作系统的输出都相同。

这也是为什么随机种子在算法调试中非常有用。

例如：

```
srand(12345);
```

你可以让程序每次生成相同的测试数据，方便复现错误。

## 四、C/C++ 中的 rand() 和 srand()

这是最基础的随机数生成方式。

需要头文件：

```
#include <cstdlib>
```

### 1. rand() 的作用

```
int x = rand();
```

`rand()` 返回一个位于以下区间的整数：

\\[ 0\le x\le RAND\\\_MAX \\]

其中 `RAND_MAX` 是一个由实现决定的常量，标准保证它至少为 `32767`。

例如：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        cout << rand() << " ";
    }
    return 0;
}
```

在相同运行环境中，如果不设置随机种子，每次重新运行通常会输出相同的序列。

因为标准规定：

没有调用 `srand()` 时，`rand()` 的行为与使用 `srand(1)` 初始化相同。

### 2. srand() 的作用

```
srand(42);
```

`srand()` 用于设置 `rand()` 的随机种子。

例如：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    srand(42);

    for (int i = 1; i <= 10; i++) {
        cout << rand() << " ";
    }
    return 0;
}
```

只要种子不变，序列就可以复现。

### 3. srand(time(0)) 的作用

```
srand(time(0));
```

这是最常见的写法。

`time(0)` 返回当前时间，通常以从 1970 年 1 月 1 日 00:00:00 UTC 起经过的秒数表示。

因为时间不断变化，所以可以利用时间作为随机种子。

完整示例：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    srand(time(0));

    for (int i = 1; i <= 10; i++) {
        cout << rand() << " ";
    }
    return 0;
}
```

不过要注意：

`time(0)` 的时间分辨率通常只有一秒。

如果在同一秒内多次启动程序，可能使用相同种子。

### 4. srand(rand()) 的作用

```
srand(rand());
```

执行顺序：

1. 调用 `rand()`，生成一个伪随机整数。
2. 将这个整数传入 `srand()`。
3. 使用它重新初始化随机数生成器。

例如：

```
srand(42);

int x = rand();

srand(rand());
```

这里第二次调用 `rand()` 产生的数字成为新的种子。

但这种做法通常没有必要。

因为 `rand()` 本身就是确定性的伪随机生成器，重新用它生成的数字设置种子，并不会凭空增加随机性。

尤其是：

```
int main() {
    srand(rand());
}
```

如果此前没有设置种子，那么第一次 `rand()` 本身就是固定的，因此每次运行使用的新种子仍然相同。

### 5. srand() 应该调用几次？

通常只调用一次。

推荐：

```
int main() {
    srand(time(0));

    for (int i = 0; i < 100; i++) {
        cout << rand() << "\n";
    }
}
```

不推荐：

```
for (int i = 0; i < 100; i++) {
    srand(time(0));
    cout << rand() << "\n";
}
```

因为循环可能在同一秒内完成。

每次使用相同的种子重新初始化，就可能导致每次输出相同的数字。

## 五、如何生成指定范围的随机数？

这是最常用的操作。

### 1. 生成 0 到 n-1

```
int x = rand() % n;
```

例如：

```
rand() % 10;
```

结果范围：

\\[ [0,9] \\]

### 2. 生成 1 到 n

```
int x = rand() % n + 1;
```

例如：

```
rand() % 10 + 1;
```

结果范围：

\\[ [1,10] \\]

### 3. 生成 a 到 b

通用公式：

\\[ \boxed{x=rand()\\%(b-a+1)+a} \\]

例如，生成 20 到 50 的整数：

```
int x = rand() % 31 + 20;
```

### 4. 为什么 rand() % n 不完全均匀？

假设 `rand()` 只能产生：

```
0 1 2 3 4 5 6 7
```

现在执行：

```
rand() % 3;
```

得到：

| 原始值 | 取模结果 |
| --- | ---- |
| 0   | 0    |
| 1   | 1    |
| 2   | 2    |
| 3   | 0    |
| 4   | 1    |
| 5   | 2    |
| 6   | 0    |
| 7   | 1    |

可以发现：

- 0 出现 3 次
- 1 出现 3 次
- 2 出现 2 次

如果原始八个值等概率出现，那么取模结果就不是严格均匀的。

这种现象称为 模偏差（Modulo Bias）。

实际的 `rand()` 还可能存在低位随机性较差等问题。

因此，如果需要更可靠的随机数分布，推荐现代 C++ 的 `<random>` 库。

## 六、现代 C++：mt19937

这是应该重点掌握的部分。

`mt19937` 是 C++11 引入的伪随机数生成器，位于：

```
#include <random>
```

它使用的是 Mersenne Twister（梅森旋转算法）。

其中：

- `mt`：Mersenne Twister
- `19937`：生成器的周期与梅森素数 \\(2^{19937}-1\\) 有关

准确地说，它的周期为：

\\[ \boxed{2^{19937}-1} \\]

这是一个极其巨大的数字。

## 七、mt19937 的基本用法

### 1. 创建生成器

```
mt19937 rng(42);
```

这里：

- `mt19937` 是生成器类型。
- `rng` 是我们给生成器起的变量名。
- `42` 是随机种子。

也可以写：

```
mt19937 gen(42);
```

变量名可以自由选择。

### 2. 生成随机数

```
cout << rng() << "\n";
```

注意这里的语法。

`rng` 是一个对象，但是可以像函数一样调用：

```
rng()
```

这是因为 `mt19937` 实现了函数调用运算符 `operator()`。

每次调用都会生成下一个伪随机整数，并更新生成器内部状态。

完整示例：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    mt19937 rng(42);

    for (int i = 1; i <= 10; i++) {
        cout << rng() << " ";
    }

    return 0;
}
```

`mt19937` 的原始输出范围是：

\\[ 0\le x\le 2^{32}-1 \\]

也就是：

\\[ 0\le x\le 4294967295 \\]

与 `rand()` 不同，标准明确规定了 `mt19937` 的生成算法及参数，因此相同种子下，其原始输出序列具有跨标准兼容实现的一致性。

## 八、mt19937 如何设置随机种子？

常见有三种方式。

### 方法一：固定种子

```
mt19937 rng(42);
```

优点：

- 结果可复现。
- 方便调试。
- 适合算法对拍。

这是我最推荐你在调试阶段使用的方法。

### 方法二：使用当前时间

```
mt19937 rng(time(0));
```

原理与 `srand(time(0))` 相似。

但依然存在一秒内种子相同的问题。

### 方法三：使用 random_device

```
mt19937 rng(random_device{}());
```

这是一种常见的初始化方式。

其中：

```
random_device{}()
```

创建一个临时 `random_device` 对象，并调用它生成一个随机值，作为 `mt19937` 的种子。

`random_device` 在部分平台上使用系统熵源，但标准允许某些实现使用伪随机机制。

## 九、mt19937 如何生成指定范围的整数？

有两种常见方法。

### 方法一：取模

```
mt19937 rng(random_device{}());

int x = rng() % 100 + 1;
```

生成 1～100 的整数。

但这里仍然可能存在模偏差。

### 方法二：uniform_int_distribution

这是更规范的方式。

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    mt19937 rng(random_device{}());

    uniform_int_distribution<int> dist(1, 100);

    for (int i = 1; i <= 10; i++) {
        cout << dist(rng) << " ";
    }

    return 0;
}
```

拆解：

```
uniform_int_distribution<int> dist(1, 100);
```

创建一个整数均匀分布对象。

范围为：

\\[ [1,100] \\]

接着：

```
dist(rng)
```

使用 `rng` 提供的随机比特，生成一个符合该分布的整数。

理论上，范围内每个整数被选中的概率相同。

注意，`uniform_int_distribution` 的具体映射算法可能因标准库实现而异，因此跨平台不一定生成相同的最终整数序列，即使底层 `mt19937` 的原始输出一致。

### rand 和 mt19937 对比

| 特性     | rand()     | mt19937           |
| ------ | ---------- | ----------------- |
| 标准支持   | C/C++      | C++11 起           |
| 随机数质量  | 实现相关，可能较差  | 通常较好              |
| 周期     | 实现相关       | \\(2^{19937}-1\\) |
| 原始输出范围 | 0～RAND_MAX | 0～\\(2^{32}-1\\)  |
| 种子设置   | srand()    | 构造时指定或 seed()     |
| 是否可复现  | 是          | 是                 |
| 是否适合竞赛 | 简单场景可用     | 推荐                |

## 十、mt19937_64 是什么？

除了：

```
mt19937 rng;
```

还有：

```
mt19937_64 rng;
```

它是梅森旋转算法的 64 位版本。

两者主要区别：

| 类型         | 单次输出位数 | 周期                |
| ---------- | ------ | ----------------- |
| mt19937    | 32 位   | \\(2^{19937}-1\\) |
| mt19937_64 | 64 位   | \\(2^{19937}-1\\) |

如果你需要生成很大的整数，例如 \\(10^{18}\\) 范围内的随机整数，可以使用：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    mt19937_64 rng(random_device{}());

    uniform_int_distribution<long long> dist(
        1LL, 1000000000000000000LL
    );

    cout << dist(rng);
}
```

在 XCPC 中，这种写法也比较常见。

## 十一、C++ 随机化常用操作

下面进入实际应用。

### 1. 随机生成数组

例如生成一个长度为 10、元素范围为 1～100 的数组。

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    mt19937 rng(random_device{}());
    uniform_int_distribution<int> dist(1, 100);

    int n = 10;
    int a[10];

    for (int i = 0; i < n; i++) {
        a[i] = dist(rng);
    }

    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```

这在生成测试数据时非常有用。

### 2. 随机打乱数组

C++ 提供了：

```
shuffle()
```

例如：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    mt19937 rng(random_device{}());

    vector<int> a = {1, 2, 3, 4, 5};

    shuffle(a.begin(), a.end(), rng);

    for (int x : a) {
        cout << x << " ";
    }
}
```

`shuffle()` 会随机排列数组元素。

与简单地反复交换随机位置相比，标准库的 `shuffle()` 更适合生成均匀的随机排列。

### 3. 随机选择一个元素

```
int x = a[dist(rng)];
```

其中 `dist` 应该被设置为合法下标范围，例如：

```
uniform_int_distribution<int> dist(0, n - 1);
```

如果数组非空，那么每个位置都可以被等概率选中。

### 4. 随机生成二维坐标

例如在 \\(n\times m\\) 的矩阵中随机选择一个位置：

```
uniform_int_distribution<int> distX(1, n);
uniform_int_distribution<int> distY(1, m);

int x = distX(rng);
int y = distY(rng);
```

这与你刚才看的 P1162 代码直接相关。

原来的代码：

```
int x = rand() % n + 1;
int y = rand() % n + 1;
```

可以改成：

```
mt19937 rng(random_device{}());

uniform_int_distribution<int> dist(1, n);

int x = dist(rng);
int y = dist(rng);
```

但要强调，换成 `mt19937` 只改善随机数生成方式，并不能修复 P1162 那份算法本身的逻辑问题。

## 十二、随机化算法的典型应用

### 1. 随机快速排序

传统快速排序中，如果总是选择第一个元素作为基准：

```
int pivot = a[l];
```

某些输入可能导致时间复杂度退化为：

\\[ O(n^2) \\]

随机化快速排序则随机选择基准：

```
uniform_int_distribution<int> dist(l, r);
int p = dist(rng);

swap(a[l], a[p]);
```

然后执行正常的快速排序划分过程。

在合理的随机选择下，快速排序的期望时间复杂度为：

\\[ \boxed{O(n\log n)} \\]

最坏时间复杂度仍然可能是：

\\[ O(n^2) \\]

随机化并没有消除最坏情况，而是降低了它发生的概率。

### 2. 蒙特卡洛算法

假设我们想估计圆周率 \\(\pi\\)。

考虑边长为 2 的正方形，以及其中半径为 1 的圆。

正方形面积：

\\[ S\_{\text{square}}=4 \\]

圆面积：

\\[ S\_{\text{circle}}=\pi \\]

所以面积之比：

\\[ \frac{S\_{\text{circle}}}{S\_{\text{square}}} =\frac{\pi}{4} \\]

如果我们在正方形中均匀随机生成大量点，那么落在圆内的点数占比可以近似表示面积之比。

因此：

\\[ \boxed{\pi\approx4\times\frac{\text{圆内点数}}{\text{总点数}}} \\]

代码：

```
#include <bits/stdc++.h>
using namespace std;

int main() {
    mt19937 rng(random_device{}());

    uniform_real_distribution<double> dist(-1.0, 1.0);

    int n = 1000000;
    int cnt = 0;

    for (int i = 0; i < n; i++) {
        double x = dist(rng);
        double y = dist(rng);

        if (x * x + y * y <= 1.0) {
            cnt++;
        }
    }

    double pi = 4.0 * cnt / n;

    cout << fixed << setprecision(8) << pi;
}
```

这里使用了：

```
uniform_real_distribution<double>
```

它用于生成均匀分布的浮点数。

与 `uniform_int_distribution` 不同，它默认使用左闭右开的区间：

\\[ [a,b) \\]

当试验次数足够多时，估计结果通常会逐渐接近真实的 \\(\pi\\)，但并不保证每次增加试验次数后误差都变小。

## 十三、随机对拍

所谓对拍，就是：

使用随机数据，对比两个程序的运行结果，寻找错误。

通常需要：

1. 一个你自己写的高效算法。
2. 一个简单但正确的暴力算法。
3. 一个随机数据生成器。

例如，假设你写了一道贪心题。

你的贪心算法很快，但不确定是否正确。

你可以写一个暴力 DFS，枚举所有可能情况。

然后随机生成大量小规模数据：

```
mt19937 rng(42);

uniform_int_distribution<int> distN(1, 10);
uniform_int_distribution<int> distA(1, 100);
```

不断生成数据，并分别运行贪心算法和暴力算法。

核心结构：

```
for (int t = 1; t <= 100000; t++) {
    // 生成随机数据

    // ans1 = 贪心算法结果
    // ans2 = 暴力算法结果

    if (ans1 != ans2) {
        cout << "Wrong Answer!\n";
        // 输出出错的数据
        break;
    }
}
```

一旦发现：

```
贪心结果：15
暴力结果：17
```

就说明你的贪心策略存在问题，或者其中某个实现有错误。

这比单纯手动构造测试数据更容易发现隐藏的边界情况。

## 十四、为什么算法竞赛经常使用固定随机种子？

假设你正在调试一个随机化算法。

第一次运行：

```
Wrong Answer
```

第二次运行：

```
Accepted
```

第三次运行：

```
Wrong Answer
```

这会让调试变得困难。

如果你使用：

```
mt19937 rng(12345);
```

那么每次运行都会得到相同的原始随机序列。

你就可以稳定地复现问题。

因此，实际开发时可以采用这样的策略：

- 调试阶段：固定随机种子。
- 随机测试阶段：可以改变种子，扩大测试覆盖范围，并记录每次使用的种子。
- 正式运行阶段：根据算法需求决定使用固定种子还是变化种子。

固定种子并不意味着随机化算法失去了意义。

它只是让随机过程变得可复现。

## 十五、推荐的 XCPC 随机数模板



```
#include <bits/stdc++.h>
using namespace std;

mt19937 rng(
    chrono::steady_clock::now()
        .time_since_epoch().count()
);

int rnd(int l, int r) {
    return uniform_int_distribution<int>(l, r)(rng);
}

int main() {
    cout << rnd(1, 100) << "\n";
    cout << rnd(10, 20) << "\n";
    cout << rnd(-100, 100) << "\n";

    return 0;
}
```

这里的：

```
int rnd(int l, int r)
```

是我们自己封装的函数。

调用：

```
rnd(1, 100);
```

就能生成 1～100 之间的随机整数。

这种写法在算法竞赛中非常方便。

不过，如果你需要生成超过 `int` 范围的整数，应当改用 `mt19937_64` 和 `uniform_int_distribution<long long>`。

## 十六、知识总结

| 概念                          | 作用          | 关键知识         |
| --------------------------- | ----------- | ------------ |
| Randomization               | 随机化         | 在算法中引入随机因素   |
| PRNG                        | 伪随机数生成器     | 通过确定算法生成随机序列 |
| Random Seed                 | 随机种子        | 初始化生成器       |
| `rand()`                    | 生成伪随机整数     | C 语言传统接口     |
| `srand()`                   | 设置种子        | 通常只调用一次      |
| `time(0)`                   | 获取当前时间      | 常用于简单种子      |
| `mt19937`                   | 32 位梅森旋转生成器 | 竞赛常用         |
| `mt19937_64`                | 64 位梅森旋转生成器 | 适合生成大整数      |
| `random_device`             | 获取随机数据      | 常用于初始化种子     |
| `uniform_int_distribution`  | 均匀整数分布      | 生成指定范围整数     |
| `uniform_real_distribution` | 均匀实数分布      | 生成浮点随机数      |
| `shuffle()`                 | 随机打乱序列      | 随机排列         |
| Monte Carlo                 | 蒙特卡洛方法      | 通过随机试验近似求解   |
| 随机对拍                        | 算法测试        | 随机生成数据寻找反例   |
