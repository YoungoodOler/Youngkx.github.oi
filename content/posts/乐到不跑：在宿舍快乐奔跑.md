## 前言

由于本人实在是懒，只愿意坐在寝室里敲电脑，再者，这破学校竟然要求每学期跑满55次，而且每次最低2公里，这我能忍吗？当然不忍了！于是乎，我决定动用一点电脑手段去完成这个任务。

## 经历

讲一下我一路走过来的心路历程吧，不想看的可以直接跳到下一章。

首先，由于我的手机是iPhone，作为一个比较封闭的系统，很多可以直接在安卓上运行的脚本都不能跑，而我一个穷学生，再买一台安卓机是不可能的，所以，我最开始想到了使用电脑安卓模拟器。

我有幸在github上找到了一个项目，是py写的，里面接入了MuMu模拟器的api，可以自动控制MuMu然后往里面输送虚拟定位，甚至可以通过摇窗口的方式往里面灌入步频信息。于是我很轻易地找了个步道乐跑的apk装在了模拟器上，之后我发现了一个问题：步道乐跑tmd只能用微信或者QQ登录！而且我最开始是用的微信登录，这意味着我一定要在模拟器上装一个微信然后去登录。

我认了，试着装了微信，但是我换了几个官方安装包，每次打开微信都闪退，最后我先安装了一个腾讯应用宝~~（嗯对流氓软件）~~，然后通过它安装微信，最后成功登录了。

然后我手机再打开微信，发现我的微信**被封了**。

不过解封还是比较容易的，后面也是顺利地进行了宿舍乐跑。

但是，昨天，我打开MuMu模拟器，发现乐跑这个破软件非要我更新，不更新就自动退出，结果更新了，直接打都打不开了。

我怀疑是官方新增了模拟器检测机制，不过最终就是打不开了。

但是跑是不可能自己跑的。

然后我开始摸索有没有电脑脚本去给iPhone灌虚拟定位的方式，因为我的iPhone打开了开发者模式，我记得Apple是开放了定位接口，用于给开发者调试软件定位功能的。

结果还真被我找到了！github上有一堆开源项目，美其名曰iOSRealRun，而且更新日期还挺近的。

于是以下是操作流程。

## 操作流程

### 1 前置条件

#### 1 安装iTunes

Windows电脑请去[苹果iTunes官网](https://www.apple.com.cn/itunes/)下载iTunes Windows版，注意不要下载微软商店版的。该软件用于和你的iPhone进行数据传输。

![往下滑找到“需要其他版本？”](/images/ledaobupao/p1.png)

之后将iPhone和电脑通过USB连接，如果你的iPhone第一次连接该电脑，会弹出“信任此电脑”的窗口，点击“信任”然后输入锁屏密码即可。

#### 2 打开开发者模式

你的iPhone要打开开发者模式才能往里面灌虚拟定位。开启方法如下：

> 设置 → 隐私与安全 → 最底下有个开发者模式  
> 打开开发者模式要求输入密码并重启

如果你没有在你的iPhone里找到开发者模式的选项，可以参考如下步骤：

1. 打开[iOS Developer Mode Helper](https://github.com/rebrma/iPhone-developer-enabler-for-WIN/releases)这个连接，在下面的Assets里找到`iOS-Developer-Mode-Helper-0.1.1-windows-x64.exe`，然后点击下载。
2. 下载好后双击打开，此时如果你连接了iPhone，软件页面上应该会显示你的设备。
3. 点击`Refresh`，然后点击`Reveal setting`。
4. 此时再回到你的iPhone，你应该就可以在相同位置找到开发者模式了。

### 2 安装iOSRealRun

该项目本身是GitHub上的一个开源项目[iOSRealRun-26](https://github.com/BixingWu/iOSRealRun-26)，但是这个项目还要自己装依赖什么的，考虑到有很多人都是电脑小白菜，所以我把它打包成了一个exe安装包，大家可以点击一键下载：[下载链接](https://www.youngkx.cn/api/files/8205430706701-bed0c9e3-76d0-4764-91e8-a3cafd7674a3)

下载完成后按照流程安装即可。

安装后你就可以在开始菜单里找到这个软件，直接打开它。

> 首次打开它会自动下载安装脚本所需要的依赖，同时会自动挂载。下载好后它会打开一个管理员powershell，点击允许。

然后它便开始自动运行脚本了，但是此时还不能用，因为它里面的操场坐标信息你还没改（默认内置重庆理工大学两江校区跑道坐标）。

然后我要在这里插一句，有些人的电脑网络原因，有候脚本在安装依赖的时候可能会由于下载失败而出现一大堆乱码，如果你发现你的powershell运行时出现了上述情况，请进行如下操作：

1. 点击下载[挂载文件](https://www.youngkx.cn/api/files/8205430602058-bfba43fe-f9c1-4d24-8d3b-067a9a1ffe75)。
2. 解压，然后会出现一个文件夹，**不要对文件夹的内容包括名字进行任何操作**，然后把这个文件夹放进iosRealRun软件的根目录里。
3. 如果你不知道根目录在哪，打开开始菜单，右键iosRealRun软件，打开文件位置，然后你会找到一个快捷方式，然后再右键它，打开文件位置，之后你就可以打开根目录了。
4. 复制根目录文件地址
> 示例:`C:\Users\11111\AppData\Local\Programs\iOSRealRun-26 `
5. 电脑上以管理员身份打开 Windows PowerShell，粘贴整段执行：
```powershell
Set-Location -LiteralPath '这里粘贴你刚刚复制的根文件夹地址，示例同上'
$env:NO_COLOR = '1'

& '.\.runtime\python.exe' -X utf8 -m pymobiledevice3 mounter mount-personalized `
    '.\DDI\Image.dmg' `
    '.\DDI\Image.dmg.trustcache' `
    '.\DDI\BuildManifest.plist'
```
看到 Personalized image mounted successfully 就挂载成功了。

> 注意，以上挂载过程全程需要**保持iPhone用 USB 连上电脑并解锁**。

### 3 填入经纬度信息

1. 浏览器直接搜一个能看经纬度的地图，然后找到你操场跑道的两个环形跑道端点的经纬度，记录下来。
2. 打开软件根目录，找到`budaolepao.txt`这个文件，然后把这个文件和第1步记录的经纬度一起发给AI，附上提示词：
```txt
用附件 `budaolepao.txt` 作为400m环形跑道跑道模板，保持点位顺序和形状，将两个环形端点对齐到我提供的经纬度，其余点按比例调整。只输出一个与附件格式一致的 TXT 文件。
```
3. 把原来根目录下的`budaolepao.txt`替换为AI给你的新文件，注意文件名称不要改变。

这样就完成了，可以运行软件然后打开导航软件测试定位是不是已经到操场了，成功就可以开始乐跑了！

> 全程只要电脑连接了iPhone就要打开iTunes，不然信息无法直接传输！

### 4 个性化设置

可以打开软件根目录下的文件`config.yaml`进行个性化设置：
```
loopCount: 5.5 // 跑5.5圈后自动暂停
targetMinutes: 10 // 目标用时10min，与速度有关
routeConfig: "Budaolepao.txt" // 坐标文件，别动，下面的也别动
libimobiledeviceDir: "libimobiledevice"
imageDir: "DeveloperDiskImage"
```

个人建议不要改设置，默认设置是跑大约2.16公里，总共用时10min，属于是正常及格速度。

> 注意，如果在程序运行中途你要推出，请在powershell界面按Ctrl + C，否则可能手机正常定位无法恢复，需要重启手机才能恢复！
