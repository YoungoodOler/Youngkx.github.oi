### 2. 基本操作

| 操作 | 时间复杂度 |
| --- | --- |
| 按下标访问、修改 | $O(1)$ |
| 遍历、在无序数组中查找 | $O(n)$ |
| 在有序数组中二分查找 | $O(\log n)$ |
| 在中间插入、删除并保持顺序（最坏） | $O(n)$ |

### 3. C++ STL 容器

长度在编译时确定用 `std::array`，需要运行时决定长度或追加元素时用 `std::vector`。`vector::push_back` 的均摊时间复杂度为 $O(1)$，扩容时已有元素可能被搬到新地址。

```cpp
#include <array>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    array<int, 3> fixed = {4, 7, 2};
    vector<int> a(fixed.begin(), fixed.end());

    a[1] = 8;
    a.push_back(9);

    for (int x : a) cout << x << ' ';
    cout << '\n';
}
```

### 4. 典型应用场景

- 用下标记录频次、访问矩阵、保存 DP 状态。
- 构造前缀和、差分数组，或在有序数组上二分。

## 链表（Linked List）

[阅读链表详解 →](/2026/11/25/algorithm-competition-data-structure/linked-list/)

### 1. 基本概念和原理

链表是一种线性数据结构，由多个节点（Node）组成，每个节点包含**数据域和指针域**，通过指针将各个节点连接起来。

与数组不同，链表的元素在内存中不需要连续存储。

常见的链表分为以下三种：

**单向链表（Singly Linked List）**

每个节点通过 next 指向下一个节点，只能向后遍历。

### 3. C++ STL 容器

C++ STL 提供了两种链表容器：

| 容器 | 类型 | 头文件 |
|--------|--------|--------|
| `list` | 双向链表 | `<list>` |
| `forward_list` | 单向链表 | `<forward_list>` |

通常使用功能更加完整的 `list`。

**常用成员函数**

| 函数 | 作用 | 时间复杂度 |
|--------|--------|--------|
| `push_front(x)` | 头部插入 | $O(1)$ |
| `push_back(x)` | 尾部插入 | $O(1)$ |
| `pop_front()` | 删除头部 | $O(1)$ |
| `pop_back()` | 删除尾部 | $O(1)$ |
| `insert(it, x)` | 在迭代器位置前插入 | $O(1)$ |
| `erase(it)` | 删除迭代器指向的元素 | $O(1)$ |
| `remove(x)` | 删除所有值为 x 的元素 | $O(n)$ |
| `front()` | 获取首元素 | $O(1)$ |
| `back()` | 获取尾元素 | $O(1)$ |
| `size()` | 获取元素数量 | $O(1)$ |
| `sort()` | 链表排序 | $O(n\log n)$ |
| `reverse()` | 反转链表 | $O(n)$ |

**代码示例**

```cpp
#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> l = {10, 20, 30};
    l.push_front(5);
    l.push_back(40);

    auto it = l.begin();
    ++it;                  // it 指向 10
    l.insert(it, 8);
    l.erase(it);
    l.remove(30);

    for (int x : l) cout << x << ' ';
    cout << '\n';
}
```

输出：

```text
5 8 20 40
```

**注意：** `list` 不支持 `l[i]`、`it + n` 等随机访问操作，但支持 `it++` 和 `it--`。

### 4. 典型应用场景

- 约瑟夫环问题。
- 频繁在序列中间插入、删除元素。
- LRU 缓存（双向链表 + 哈希表）。
- 模拟队列、双端队列等数据结构。

在算法竞赛中，链表的使用频率低于数组和 `vector`。当需要频繁修改已知位置的元素连接关系时，链表才具有明显优势。

只存键用 `std::unordered_set`，存键值对用 `std::unordered_map`。对不存在的键使用 `freq[key]` 会创建一项，只想查询时使用 `find`。

```cpp
#include <iostream>

int main() {
```

$\alpha(n)$ 增长极慢。以上界限使用路径压缩和按大小合并。 [Tarjan 的并查集分析](https://www2.eecs.berkeley.edu/Pubs/TechRpts/1974/28764.html)

### 3. C++ 代码实现

STL 没有对应容器。编号从 `0` 开始，`parent[x]` 记录父节点，`sz[root]` 记录集合大小。

```cpp
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;

int find_root(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find_root(parent[x]);
}

void unite(int a, int b) {
    a = find_root(a);
    b = find_root(b);
    if (a == b) return;
    if (sz[a] < sz[b]) swap(a, b);
    parent[b] = a;
    sz[a] += sz[b];
}

int main() {
    parent.resize(4);
    sz.assign(4, 1);
    iota(parent.begin(), parent.end(), 0);

    unite(0, 1);
    unite(1, 2);
    cout << (find_root(0) == find_root(2)) << '\n';
    cout << sz[find_root(0)] << '\n';
}
```

| 操作 | 时间复杂度 |

### 3. C++ 代码实现

STL 没有暴露节点结构的普通二叉搜索树容器。下面用数组下标记录左右孩子，演示插入和查找。

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Node {
    int key, left = 0, right = 0;
};

vector<Node> tree(1);

int insert(int p, int x) {
    if (p == 0) {
        tree.push_back({x});
        return int(tree.size()) - 1;
    }
    if (x < tree[p].key) {
        int child = insert(tree[p].left, x);
        tree[p].left = child;
    } else if (x > tree[p].key) {
        int child = insert(tree[p].right, x);
        tree[p].right = child;
    }
    return p;
}

bool contains(int p, int x) {
    while (p != 0) {
        if (x == tree[p].key) return true;
        p = x < tree[p].key ? tree[p].left : tree[p].right;
    }
    return false;
}

int main() {
    int root = 0;
    int a[] = {8, 3, 10, 1, 6};
    for (int x : a) root = insert(root, x);

    cout << contains(root, 6) << '\n';
    cout << contains(root, 7) << '\n';
}
```

```cpp
#include <iostream>
```

### 3. C++ STL 容器

使用 `std::priority_queue`，默认是大根堆。传入比较器 `std::greater<int>` 可以得到小根堆。`top()` 读取堆顶，`pop()` 删除堆顶。 [C++ 标准工作草案](https://eel.is/c++draft/priority.queue)

```cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    priority_queue<int> big;
    priority_queue<int, vector<int>, greater<int>> small;
    int a[] = {9, 7, 6, 4};
    for (int x : a) {
        big.push(x);
        small.push(x);
    }

    cout << big.top() << ' ' << small.top() << '\n';
    big.pop();
    cout << big.top() << '\n';
}
```

### 4. 典型应用场景

- Dijkstra 维护当前待处理的最短距离。
- 维护前 $k$ 大元素时使用大小为 $k$ 的小根堆。
- 多路归并、霍夫曼编码、按优先级安排任务。

| --- | --- |

固定字母表时，可以用数组直接找下一条边。若有 $M$ 个节点，下面的实现为每个节点保存 26 个孩子下标，空间为 $O(26M)$。

### 3. C++ 代码实现

STL 没有对应容器。下面的实现接受小写英文字母。用 `0` 表示没有这条边，根节点编号也是 `0`，新节点从 `1` 开始编号。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Node {
    int next[26]{};
    bool end = false;
};

vector<Node> trie(1);

void insert(const string& s) {
    int p = 0;
    for (char ch : s) {
        int c = ch - 'a';
        if (trie[p].next[c] == 0) {
            trie.push_back({});
            trie[p].next[c] = int(trie.size()) - 1;
        }
        p = trie[p].next[c];
    }
    trie[p].end = true;
}

int walk(const string& s) {
    int p = 0;
    for (char ch : s) {
        p = trie[p].next[ch - 'a'];
        if (p == 0) return -1;
    }
    return p;
}

int main() {
    insert("cat");
    insert("car");

    int p = walk("cat");
    cout << (p != -1 && trie[p].end) << '\n';

    p = walk("ca");
    cout << (p != -1 && trie[p].end) << '\n';
    cout << (p != -1) << '\n';
}
```

### 2. 基本操作

| 操作 | 时间复杂度 |
| --- | --- |
| 预处理 $n$ 个元素 | $O(n\log n)$ |
| 查询区间最小值 | $O(1)$ |

空间为 $O(n\log n)$。这份模板适合静态数组。查询闭区间 `[l, r]` 时，取两段长度 $2^k$，分别贴在左右两端，其中 $k=\lfloor\log_2(r-l+1)\rfloor$。

### 3. C++ 代码实现

STL 没有对应容器。下面的模板使用从 `0` 开始的下标，要求查询满足 `0 <= l <= r < n`。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<int> lg;
vector<vector<int>> st;

void build(const vector<int>& a) {
    int n = int(a.size());
    lg.assign(n + 1, 0);
    for (int len = 2; len <= n; ++len) lg[len] = lg[len / 2] + 1;

    st.assign(lg[n] + 1, vector<int>(n));
    st[0] = a;
    for (int k = 1; k <= lg[n]; ++k) {
        for (int i = 0; i + (1 << k) <= n; ++i) {
            st[k][i] = min(st[k - 1][i], st[k - 1][i + (1 << (k - 1))]);
        }
    }
}

int query(int l, int r) {
    int k = lg[r - l + 1];
    return min(st[k][l], st[k][r - (1 << k) + 1]);
}

int main() {
    build({8, 7, 5, 2, 9, 4, 6, 3});
    cout << query(1, 6) << '\n';
}
```

查询时减去 `lowbit`，逐段向左累加。修改时加上 `lowbit`，更新所有包含该位置的块。空间为 $O(n)$。

### 3. C++ 代码实现

STL 没有对应容器。下面从 `1` 开始编号，`sum(i)` 查询 `[1, i]`，闭区间 `[l, r]` 的和为 `sum(r) - sum(l - 1)`。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<long long> bit;

void add(int i, int delta) {
    for (; i <= n; i += i & -i) bit[i] += delta;
}

long long sum(int i) {
    long long ans = 0;
    for (; i > 0; i -= i & -i) ans += bit[i];
    return ans;
}

int main() {
    int a[] = {1, 2, 3, 4};
    n = 4;
    bit.assign(n + 1, 0);
    for (int i = 1; i <= n; ++i) add(i, a[i - 1]);

    cout << sum(4) - sum(1) << '\n';  // [2, 4]
    add(3, 5);
    cout << sum(4) - sum(1) << '\n';
}
```

- 离散化后统计逆序对，维护值域上的动态频次。

### 2. 基本操作

| 操作 | 时间复杂度 |
| --- | --- |
| 建树 | $O(n)$ |
| 单点修改 | $O(\log n)$ |
| 区间查询 | $O(\log n)$ |
| 区间修改（支持懒标记时） | 通常为 $O(\log n)$ |

懒标记把整段修改先记在节点上，查询或修改需要深入时再下传。下面的模板只实现单点赋值和区间求和。

### 3. C++ 代码实现

STL 没有对应容器。下面把叶子数补到二次幂，用数组存树。`set_value(i, x)` 做单点赋值，`query(l, r)` 查询从 `0` 开始编号的半开区间 `[l, r)`。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int base;
vector<long long> tree;

void build(const vector<int>& a) {
    base = 1;
    while (base < int(a.size())) base *= 2;
    tree.assign(2 * base, 0);

    for (int i = 0; i < int(a.size()); ++i) tree[base + i] = a[i];
    for (int p = base - 1; p > 0; --p) tree[p] = tree[2 * p] + tree[2 * p + 1];
}

void set_value(int i, int x) {
    int p = base + i;
    tree[p] = x;
    for (p /= 2; p > 0; p /= 2) tree[p] = tree[2 * p] + tree[2 * p + 1];
}

long long query(int l, int r) {
    long long ans = 0;
    for (l += base, r += base; l < r; l /= 2, r /= 2) {
        if (l % 2 == 1) ans += tree[l++];
        if (r % 2 == 1) ans += tree[--r];
    }
    return ans;
}

int main() {
    build({1, 2, 3, 4});
    cout << query(1, 4) << '\n';
    set_value(2, 8);
    cout << query(1, 4) << '\n';
}
```

### 4. 典型应用场景

- 动态区间最值和区间和。
- 配合懒标记完成区间加法或赋值，再查询区间和、最值。
- 用树上二分查找第一个满足条件的位置，例如在非负数组上查找最早达到给定前缀和的下标。
