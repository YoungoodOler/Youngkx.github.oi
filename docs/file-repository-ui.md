# 文件仓库页面

- 首页 Cards 的 Repo 卡片及顶栏右侧 Repo 入口进入 `/repo/`，Links 入口直接进入 `/links/`。
- Links、Repo 及其管理页共用右侧 Links / Repo 导航，当前栏目会标记；手机端保留直接入口，其余主导航可通过菜单展开。
- `/repo/manage/` 通过同一个 manage token 管理文件，复用 Links 管理页的当前标签页会话。锁定或接口返回 401 后会清除会话。
- 公开页移除标题上方的 YOUNGKX / FILE REPOSITORY 和 Cards / Repo 面包屑。自建文件夹名称放在切换栏，默认展示第一个文件夹；点击其他名称直接切换下方文件列表。列表包含文件名、说明、大小、上传日期和下载按钮，支持排序和分页。搜索按文件名及说明匹配整个仓库，自动读取所有剩余分页，包含其他文件夹及已有未分类文件，结果标明所属文件夹；搜索未完成或分页失败时明确提示，避免误报无匹配。清空搜索恢复原文件夹，点击文件夹则清空搜索。不提供预设分类；没有文件夹时显示创建入口。
- 常见图片与视频文件名显示 Preview 入口，点击后在弹窗中预览，视频使用浏览器原生播放控件，支持 Range 分段读取。可通过关闭按钮、Esc 或背景关闭，并恢复触发按钮焦点。保留独立下载入口；浏览器无法解码或预览请求失败时提示下载。仅点击后请求媒体正文，不预先加载全库缩略图。
- 管理页支持创建、重命名及删除空文件夹；上传必须选择文件夹，也可编辑文件将其移动到其他文件夹。已有根目录文件保留在管理页的 Unfiled 栏中，可移动到自建文件夹；不自动迁移或删除。另支持上传进度与取消、修改名称和说明、确认删除，以及保存仓库标题、上传限制和公开下载开关。暂停公开不会删除文件。
- 尚未配置存储、接口失败、加载中、无文件、无匹配和暂停公开分别显示相应状态。

接口和部署配置见 [文件仓库接口文档](file-repository-api.md)。普通 Next.js 开发服务器不包含 Worker API，完整联调需要构建后使用 Wrangler 本地预览。

按用户授权，本地预览可使用命令行 `LINKS_LOCAL_PREVIEW:true` 直接进入管理页，不需要绑定 token；此选项不写入生产配置。没有配置管理密钥的服务器会明确报告配置缺失，不再误报 token 输入错误。

Stored 会按容量自动使用 B、KiB、MiB、GiB，达到 1 GiB 后显示为 GiB。Settings 的单文件限制改为 GB 输入，默认 1、最高 5，支持小数；输入 1 对应接口中的 1024 MiB，保存时换算为整数 MiB，已有设置保留原值。超过 32 MiB 的文件会自动分片上传，显示整文件进度，暂时断网时会重试当前分片，最多三次；取消会中止并清理上传会话。文件仅在全部上传完成后显示在公开列表。刷新页面后需要重新选择文件上传。

## 前端结构

`components/FileRepository.tsx` 提供公开列表，`components/FileRepositoryManager.tsx` 提供管理界面，`components/RepositoryShared.tsx` 提供页面外壳和请求处理。页面样式位于 `app/repo/repo.css`，复用站点主题变量和背景。

`components/ResourceNav.tsx` 复用资源导航；`components/repository-upload.ts` 处理单次和分片上传、重试、取消与进度。

首页专用样式位于 `app/home.css`，仅由 `app/page.tsx` 引入；公共样式保留在 `app/globals.css`。界面字体变量为 `--ui`，Cards 的颜色及高光变量为卡片作用域内的 `--tone` 和 `--glow`。

性能检查按每个导出页面实际加载的 CSS 执行原有 64 KiB raw / 16 KiB Brotli 限制，不把不同路由各自加载的样式相加作为单页开销。

## 验证

分页尚未读完时，公开页和管理页不会将当前尚未加载到文件的文件夹标为空目录，而是提示继续加载。管理页在加载更多文件后保留 Unfiled 选择；公开及管理页遇到未推进的分页游标会保留已有列表、提示错误并允许重试。

`tests/e2e/repo.spec.ts` 覆盖公开文件夹与列表交互、跨文件夹和全部分页搜索及失败重试、图片预览与关闭、真实 WebM 播放及媒体下载字节校验、分页和错误状态、token 校验与失效、导航入口，以及通过真实本地 R2 的文件夹创建、重命名、非空删除拦截、上传、移动、说明编辑、下载字节校验、暂停和删除。测试使用独立的 8788 端口与 `.wrangler/e2e-state`，避免干扰 8787 的人工预览数据。测试数据会清理，仓库设置会恢复；身份验证的界面测试使用测试响应，真实 token 鉴权另由后端运行时测试覆盖。

大文件测试通过桌面浏览器上传 100 MiB 加 211 字节的实际文件，模拟首片临时失败并重试，确认合并前未公开，再下载并逐字节计算 SHA256 比较。取消测试覆盖桌面及手机布局。
